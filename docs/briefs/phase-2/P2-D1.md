# P2-D1: Ollama level drafter
Owns: `tools/draft-levels.ts`, `tools/draft-levels.test.ts`

A script that asks a local Ollama model to draft level JSON files.
Usage: `npx tsx tools/draft-levels.ts --region motion-plains --count 6 --model qwen3:14b [--out packages/curriculum/levels/drafts]`
1. POST to `${OLLAMA_HOST ?? 'http://localhost:11434'}/api/chat` with `stream: false` and `format` set to a JSON Schema object that mirrors `LevelSchema` (hand-write it in the script; no new dependency).
2. The prompt includes: the region's skills from `catalog.ts` (ids + names + prerequisites), all earlier skills (to require, cumulatively), the level types, 2 short example levels you write by hand, and rules: tiny buffers (3-8 lines), a story intro of max 2 sentences, hints from vague to specific, `requires` must only use skills from earlier levels or regions.
3. Validate each answer with `parseLevel`. On failure, send the zod error back once and retry. Still invalid: write it to `<out>/rejected/<n>.json` with the error, and continue.
4. Write valid drafts to `<out>/<id>.json`. Print a summary table (id, valid, retries).
5. Tests mock `fetch` (no network in tests): valid answer, invalid-then-fixed, invalid twice, Ollama unreachable (clear error message).
Your sandbox cannot reach Ollama; that is expected. The orchestrator runs the script for real afterwards.
