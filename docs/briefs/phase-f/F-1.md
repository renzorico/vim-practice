## 1. Engine: text objects
After an operator (`d`, `c`, `y`) and in visual mode (`v`, `V`), accept Vim's text objects:
- words: `iw aw iW aW`;
- quotes: `i" a" i' a' i\` a\``;
- brackets: `i( a( ib ab i) a)`, `i[ a[ i] a]`, `i{ a{ iB aB i} a}`, `i< a<  i> a>`;
- tags: `it at`;
- paragraphs: `ip ap`.
Counts as Vim does: `2daw`, `d2aw`, `v3iw`, `d2i(` (the second enclosing pair), `2dap`. The operator's `CommandRecord.motion` is the object (`'iw'`, `'a('`), the id the full command (`'diw'`, `'ci"'`). `.` repeats an operator with a text object, as with any motion (`ciwx<Esc>` then `w.`). Linewise or charwise exactly as Vim decides (`dap` is linewise; `di(` over lines is charwise with Vim's special cases: follow Neovim).
When the cursor is not inside or before an object Vim can use (`ci"` with no quote on the line, `di(` outside any parentheses), it is an engine error with no change, as Vim beeps. Vim's "search forward on the line" rule for quotes applies (`ci"` from the line start changes the first quoted string).
